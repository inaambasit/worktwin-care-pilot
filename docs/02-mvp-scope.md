# MVP Scope

## In scope for MVP

### Employee side
- Ask policy/process questions
- Receive source-cited answers
- Plain-English explanation mode
- Micro-quiz mode
- Scenario practice mode
- Private development notes
- Onboarding checklist

### Admin side
- Upload documents
- Approve documents
- Assign documents to roles/departments
- Set escalation contacts
- View anonymised question trends
- View unanswered questions
- Basic audit log

### AI behaviour
- Answer from approved documents only
- Cite the source document and section/page where available
- Escalate sensitive issues
- Refuse to guess where documentation does not support the answer
- Avoid legal, medical, employment or disciplinary decision-making

## Out of scope for MVP

Do not build these yet:
- employee monitoring
- productivity tracking
- sentiment scoring
- performance scoring
- automated disciplinary recommendations
- wellbeing diagnosis
- payroll changes
- HRIS integration
- email/calendar ingestion
- full LMS/SCORM support
- Microsoft Teams/Slack integration
- full enterprise SSO
